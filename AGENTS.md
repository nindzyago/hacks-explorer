# Hacks Explorer — правила для агентов и участников

Открытый интерактивный справочник по кибербезопасности: статический сайт, где каждая атака и
защита от неё показаны по шагам на схеме. Для новичков, с уровнем «Глубже» для тех, кому нужны
детали. Русский и английский, другие языки через pull request.

Часть 1 — законы, они важнее всего остального. Часть 2 — как работать.

---

# Часть 1 — Законы

## L0. Сайт не ломается, урок не врёт формой

1. Неверный урок, перевод или словарь останавливает gate, а не падает у читателя. На сайте нет
   пустых экранов: любая ошибка показывается сообщением с выходом в каталог.
2. Все входные данные враждебны: адрес страницы, `localStorage`, файлы уроков из pull request.
   Никаких `!`, `any` и непроверенных приведений типов вне тестов.
3. Каждое исправление падения приходит с тестом, который падал до исправления.

## L1. Ассеты и лицензии

1. Код под MIT. Тексты и схемы уроков под CC BY-SA 4.0. Каждый ассет записан в `ATTRIBUTION.md`.
2. Зависимости только с лицензиями MIT, Apache-2.0, BSD, ISC, Zlib, MPL-2.0 без изменений;
   шрифты под SIL OFL.
3. Сомневаешься — не добавляй.

## L2. Чужие материалы остаются снаружи

`reference/` только локально. Тексты, сценарии уроков, иллюстрации и код Hacksplaining,
PortSwigger, Protocol Explorer, Attack Explorer и любых других закрытых ресурсов не копируются и не
пересказываются близко к тексту. От них берётся перечень тем и идея жанра. Факты берутся из
открытых источников (OWASP, MITRE, NVD, RFC) и пишутся своими словами.

## L3. Только с человеком

Агент сам решает всё остальное (и записывает в `docs/decisions.md`), но останавливается и
спрашивает перед тем как:
- добавить зависимость или ассет вне списка лицензий;
- потратить деньги;
- отправить в удалённый репозиторий, опубликовать, выложить, выпустить;
- сделать необратимое в git или с данными;
- начать задачу `[design]` без утверждённого дизайна в `plan/designs/`;
- сделать что-то, о чём законы молчат.

## L4. Учим понимать, а не взламывать

1. Урок показывает механизм на вымышленной системе. Никаких готовых к запуску эксплойтов,
   инструментов атаки и пошаговых инструкций против реальных продуктов и версий.
2. Все IP-адреса и домены только из учебных диапазонов (RFC 5737, RFC 3849, RFC 2606).
   Проверяет gate.
3. У каждого урока об атаке есть режим «С защитой» и раздел «Как защититься». Проверяет gate.

## L5. Каждый факт проверяем

1. У каждого урока есть список открытых источников. Номера CVE и CWE, оценки CVSS и даты
   совпадают с NVD и MITRE. Проверяет gate там, где это данные, и верификатор по рубрике R-FACT.
2. Не уверен в факте — не пиши его.

## L6. Никакой слежки

Нет аналитики, кук, внешних шрифтов и скриптов, запросов к чужим серверам. Изменить это может
только владелец.

# Часть 2 — Как работать

Порядок работы над задачей: `docs/workflow.md`. Источники правды: `plan/STATUS.md`,
`plan/execution-plan.md`, `plan/architecture.md`, `plan/content-catalog.md`,
`reference/REFERENCE.md`, `scenarios/`, решения в `docs/decisions.md`.

## Сессия

1. Прочитать этот файл, `plan/STATUS.md` и три последние записи `log/devlog.md`.
2. Взять следующую задачу из STATUS, записать её в `plan/claims.md`.
3. Тест до кода, маленькие шаги, `npm run gate` зелёный перед коммитом.
4. Коммит `<id задачи>: <что сделано>`, запись в devlog, отметка в STATUS.

## Команды

| Команда | Что делает |
|---|---|
| `npm ci` | поставить зависимости |
| `npm run gate` | единственная проверка: формат, линт, типы, тесты, структура, сборка, браузерные тесты |
| `npm run e2e` | только браузерные тесты (Playwright, Chromium без окна) |
| `npm run content` | только проверка уроков в `content/` |
| `npm run budget` | размер первой загрузки и файлов уроков (после сборки; входит в gate) |
| `npm run dev` | сайт на `localhost:5173` |
| `npm run build` | сборка в `dist/` |

Папка `prototype/` — макет для оценки (K6): в gate не входит, код из неё не наследуется.

## Инварианты архитектуры

- Урок — данные, не код. Код не знает конкретных уроков.
- Всё есть команда: интерфейс, клавиатура, тесты и канал управления вызывают команды по id.
- Урок — один Markdown-файл на язык (K21); служебные строки одинаковы во всех языках.
- Время подменяемо: анимация идёт от часов плеера, а не от системных.
- Цвета и размеры только из токенов.
- Ядро не импортирует интерфейс; контент не импортирует код. Проверяет gate.
