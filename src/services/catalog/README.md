# src/services/catalog — каталог и уроки для сайта

Слой L1: импортирует только `src/core`. Загружает данные, которые сборка кладёт в `data/`
(решение K37), и проверяет их форму: любой файл — враждебный ввод (L0.2), он мог испортиться,
оборваться или оказаться другим уроком. Результат — данные или типизированная ошибка, исключений
нет. Markdown сайт не разбирает (K31).

## API

```ts
import { createLessonLoader } from './catalog';

const loader = createLessonLoader({
  fetch: (url) => window.fetch(url), // любой FetchLike; в тестах — свой
  base: import.meta.env.BASE_URL, // по умолчанию '/'
});

const catalog = await loader.catalog();
// { ok: true, value: { format: 1, lessons: [{ id, section, wave, translations: [{ language, title, hash }] }] } }

const lesson = await loader.lesson('B1', 'ru'); // id и язык могут быть чем угодно (из адреса)
if (!lesson.ok) {
  lesson.error.code; // 'not-found' | 'network' | 'bad-data'
  lesson.error.message; // английский, для журнала и сообщения на экране
}
```

Форма данных — `src/core/lesson/site.ts` (`SiteCatalog`, `SiteLesson`), проверка формы —
`src/core/lesson/site-read.ts`.

## Поведение

| Случай | Ответ |
|---|---|
| урока или языка нет в каталоге (в том числе `undefined`, `__proto__`, `../B1`) | `not-found`, файл урока не запрашивается |
| сервер ответил 404 | `not-found` |
| сервер ответил другой ошибкой, сеть упала, `fetch` бросил исключение | `network` |
| не JSON, больше 128 КБ, не та форма, другой урок или язык, `index.html` вместо файла | `bad-data` с путём до места ошибки (`steps[0].kind: expected …`) |

- Успешный каталог и уроки хранятся в загрузчике; ошибка не хранится, следующий вызов
  спрашивает снова.
- Урок ищется по каталогу: имя файла `data/lessons/<id>.<язык>.<hash>.json`, hash меняется с
  содержимым, поэтому старый урок из кэша браузера не подменит новый.
- Проверка формы строит новые объекты: лишние поля и `__proto__` отбрасываются; вложенность
  текста глубже 32 и списки длиннее 2000 — `bad-data`.
- Шаг и зона ссылаются только на участников урока; ссылки источников только `https://`.

## Ограничения

- Отмены запроса нет: если пользователь ушёл со страницы, ответ всё равно придёт и сохранится.
- Каталог загружается целиком; при 36 уроках на двух языках это около 6 КБ (оценка, не замер).
