# src/services/router — адрес страницы

Слой L1: импортирует только `src/core`. Положение в уроке живёт в адресе (архитектура §5,
M2.2): ссылка открывает тот же урок, шаг и режим защиты (сценарий S4). `address.ts` — чистый
разбор и запись строк; `router.ts` — тонкий переходник к `window.location` и `history`, которому
передают хранилище состояния и функцию запуска команд.

## Грамматика (K78)

```
/<язык>/lesson/<урок>[#step-<n>[-defence]]
/ru/lesson/B1                  шаг 1, без защиты
/ru/lesson/B1#step-3           шаг 3, без защиты
/ru/lesson/B1#step-3-defence   шаг 3, с защитой (S4)
/ru/lesson/B1#step-1-defence   шаг 1, с защитой
```

- `<язык>` — `[a-z]{2,3}(-[a-z0-9]{2,8})?` без учёта регистра. Язык, которого у сайта нет
  (список — `content/locales/languages.md`, сейчас только `ru`), и адрес без языка (`/`)
  получают язык читателя `preferred`: сохранённый выбор, иначе язык браузера (M2.3, K96).
- `<урок>` — `[A-Za-z][0-9]{1,3}`, как у команды `lesson.open`; пишется заглавной.
- `n` — 1–4 цифры, обрезается до 1…100; плеер обрезает дальше до шагов урока, когда тот
  загрузится, и адрес следует за ним (`#step-99` в B1 становится `#step-5`).
- Глубины объяснения и скорости в адресе нет (K80): глубина принадлежит читателю (K71),
  скорость — настройка (архитектура §5).

## Поведение

| Адрес | Что происходит |
|---|---|
| `/`, `/ru`, `/ru/`, `/ru/lesson` | урок по умолчанию (`initialState().lesson`, сейчас B1); адрес переписывается `replaceState` |
| `/RU/lesson/b1/`, `/en/lesson/B1` | прощается и переписывается в канонический вид `replaceState` |
| хэш вне грамматики (`#defence`, `#step-3-defense`, `#<script>`, длиннее 32 знаков) | шаг 1 без защиты, хэш убирается |
| урок по грамматике, которого нет (`/ru/lesson/Z9`) | `lesson.open Z9`, загрузчик отвечает `not-found`, страница показывает «Не удалось открыть урок» и «На главную» |
| любой другой путь (`__proto__`, `..%2FB1`, `/ru/lesson/B1/x`, кириллица, длиннее 64 знаков) | `notFound` = true: «Такой страницы нет» и «На главную»; команды не запускаются, адрес не трогается (K81) |

- Ничего не декодируется: `%42%31` — не `B1`, а неизвестная страница.
- Адрес → состояние только командами (K13): `locale.set`, если язык другой (M2.3);
  `lesson.open`, если урок другой; `defence.set`, если режим другой; `player.goto`, если шаг
  другой. Совпадающее не трогается, поэтому `startedMs`
  не сбрасывается без причины, и `/` у тестов детерминизма даёт тот же дамп, что и раньше.
- Состояние → адрес: подписка на хранилище. Другой урок — `pushState` (новая запись истории,
  «назад» возвращает к прошлому уроку на его шаге); шаг, режим и язык — `replaceState` (K79,
  M2.3: смена языка не добавляет запись истории, «назад» уводит к прошлому уроку).
  Автопроигрывание переписывает адрес на каждом шаге — без новых записей.
- `popstate` и `hashchange` применяют адрес снова; применение идемпотентно, поэтому двойное
  событие при ручной правке хэша запускает команды один раз.
- Пока адрес — неизвестная страница, состояние адрес не пишет, клавиши плеера не работают;
  уйти можно ссылкой «На главную».
- Адреса ресурсов сборки абсолютные (`/assets/…`, `/fonts/…`, `/data/…`, Vite `base` = `/`),
  поэтому глубокая ссылка грузится на сервере с SPA-откатом; проверяет
  `e2e/production/address.spec.ts`.

## Ограничения

- Язык живёт в `state.locale` (M2.3); адрес пишет его из состояния.
- На черновых адресах Cloudflare (preview) глубокая ссылка работает только для браузера (G15).
- Если урок открыт командой, пока показана «Такой страницы нет», адрес не меняется.
- Шаблон id урока повторяет `LESSON_ID` из `src/commands/player.ts` (слой ниже не может его
  импортировать); при смене формата id менять оба.
