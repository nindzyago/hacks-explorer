# src/services/i18n — языки сайта

Слой L1: импортирует только `src/core`. Тексты интерфейса на языке страницы и выбор языка для
посетителя (M2.3, дизайн `plan/designs/M2.3.md` r2, K94–K97, K105–K107).

## Где что лежит

| Что | Где |
|---|---|
| Языки сайта | `content/locales/languages.md` — `` - `ru` Русский ``, база первой |
| Строки интерфейса | `content/locales/<язык>/ui.md` — `` - `ключ` Текст ``, `{имя}` — подстановка |
| Ключи для кода | `keys.ts` — `UI_KEYS` в порядке русского файла; тест держит их равными ему |
| Разбор и полнота | `src/core/i18n` (`ui-file.ts`, `languages-file.ts`, `locales.ts`) — только при сборке |
| Сборка | `scripts/lesson-data.ts` — модуль `virtual:site-locales` со строками языков сайта |

## Формат `ui.md` (K105)

```
# Интерфейс
`ui` ru · `format` 1
## Плеер                         ← группа для переводчика, коду не важна
- `player.status` Шаг {step} из {count}
```

- Ключ — `слово.часть[.часть…]` (2–5 частей, латиница и цифры); дубль — ошибка.
- Текст — простая строка до 300 знаков; без HTML, NUL, управляющих символов и символов смены
  направления; фигурные скобки только вокруг имени подстановки.
- Остальные строки файла — заметки переводчику, их не читают; строка, начатая с `-` или `#`,
  обязана быть строкой или группой.
- Каждый `ui.md` (и языка, которого ещё нет на сайте) сверяется с русским: те же ключи, в каждой
  строке те же `{имена}`. Лишний ключ — ошибка: новая строка сначала появляется в русском файле.

## Полнота (K94, S9)

Для каждого языка из `languages.md`: есть каждый урок (`content/lessons/<урок>/<язык>.md`),
`ui.md` со всеми ключами русского и словарь с теми же терминами. Иначе gate красный и печатает
`файл:1:1: …` на каждый недостающий урок, ключ и файл. Язык с файлами, но не из списка,
проверяется, но на сайт не попадает (ни в каталог, ни в данные, ни в строки). Язык добавляется
в список в том же pull request, где переведено всё; заголовки урока и словаря для него — одна
строка в `src/core/lesson/headings.ts` и `src/core/glossary/words.ts` (иначе тоже ошибка).

## API

```ts
import siteLocales from 'virtual:site-locales';
const locales = readLocales(siteLocales); // { ok, value: { languages, strings } } — проверка формы
const t = translator(locales.value.strings['ru']); // Translate = (key: UiKey, params?) => string
t('player.status', { step: 3, count: 5 }); // «Шаг 3 из 5»
formatNumber(t, 0.5); // «0,5» по-русски, «0.5» по-английски

chooseLanguage({ stored, browser: navigator.languages, languages: ['ru', 'en'] });
storedLanguage(() => localStorage); // никогда не бросает
rememberLanguage(() => localStorage, 'en'); // никогда не бросает
```

`t` синхронный: строки всех языков сайта в первой загрузке (≈ 2 КБ gzip на язык; решение K105).
Ключ — тип `UiKey`, опечатка — ошибка типов. Недостающего ключа на сайте быть не может: gate
проверяет полноту, `readLocales` — что у каждого языка есть каждый ключ.

Ядро слов не хранит: функции `src/core` (сцена, лента, описания для экранных читалок) получают
`t` параметром и называют свои ключи (`MarkKey`, `DescribeKey`), см. `src/core/i18n/say.ts`.

## Язык посетителя (D3, K96, K107)

1. Адрес: `/<язык>/…` с языком сайта — он и есть.
2. Иначе (адрес `/` или язык, которого у сайта нет): выбор, сохранённый раньше
   (`localStorage['hacks-explorer.language']`), если такой язык есть.
3. Иначе первый из `navigator.languages`, который есть на сайте; украинский, белорусский и
   казахский читают по-русски.
4. Иначе английский, если он есть; иначе первый язык сайта.

Запоминается язык, на который читатель перешёл после открытия страницы (переключатель,
«назад», канал управления); язык из открытого адреса не запоминается. Хранилище враждебно:
недоступное, бросающее или с чужим значением — пропускается.

## Ограничения

- Пока на сайте только русский: переключателя нет, `locale.set en` — `invalid-params`.
  Английский интерфейс написан (`content/locales/en/ui.md`) и проверяется; английские уроки и
  словарь — M2.3b.
- S5 проверяется на e2e-сборке с двумя языками (`npm run build:e2e-i18n`, K106): уроки и словарь
  из `e2e/fixtures/i18n/`, строки интерфейса — настоящие.
- Слово над сообщением на сцене меряется по числу букв, как и раньше (K65); в языке с более
  длинными словами оно раньше сжимается (не уже 85 %). Проверено глазами только на учебном уроке.
- `<meta name="description">` в `index.html` остаётся русским (страница статическая).
