# src/commands — реестр команд

Слой L2: может импортировать `src/core` и `src/services`, ничего не знает о Svelte и DOM.
Всё, что делает пользователь, — команда; интерфейс, клавиатура, тесты и канал управления
вызывают её по id (архитектура §3, решение K12).

## API

```ts
import { createRegistry } from './registry';

const registry = createRegistry<AppState>(() => appState); // откуда брать состояние для enabled

registry.register({
  id: 'player.goto', // область.действие
  titleKey: 'command.player.goto', // ключ названия в файлах языка
  params: { step: { kind: 'integer', min: 0, max: 99 } },
  enabled: (state) => state.lessonOpen, // нет поля — команда доступна всегда
  run: ({ step }) => {
    /* step: number, уже проверен */
  },
});

registry.run('player.goto', { step: 3 }); // { ok: true } | { ok: false, error }
registry.list(); // [{ id, titleKey, params, enabled }]
```

Виды параметров (`params.ts`): `string` (`maxLength`, по умолчанию 200), `integer` и `number`
(`min`, `max`), `boolean`, `enum` (`values`). У любого может быть `optional: true`. Описание —
простые данные, `list()` отдаёт его как есть, оно переживает JSON.

## Поведение

- `run(id, params)` никогда не бросает исключение. Ошибка — простые данные
  `{ code, commandId, message, problems? }`:

  | code | когда |
  |---|---|
  | `unknown-command` | такого id нет; id не строка |
  | `invalid-params` | параметры не подошли; `problems` — список `{ param, problem }` |
  | `disabled` | `enabled(state)` вернула `false` |
  | `failed` | `run` или `enabled` команды бросили что угодно, в том числе значение, которое нельзя напечатать (`unprintable error`) |

- Порядок проверок: id, параметры, `enabled`, запуск. Плохой вызов виден в любом состоянии.
- Параметры враждебны (L0.2). Ничего не приводится: `"3"` — не число, `"true"` — не boolean.
  Лишний параметр — ошибка. Принимается только простой объект (или `undefined` вместо пустого);
  каждое значение читается один раз, команда получает новый объект только с описанными полями.
  Отсутствующий необязательный параметр — `undefined`. У этого объекта нет прототипа, поэтому
  параметр может называться `constructor` или `toString`, а `params.toString()` вызвать нельзя.
- `register` бросает `CommandDefinitionError` с `code`: `duplicate-id` или `invalid-definition`
  (id не вида `область.действие`, пустой `titleKey`, плохое описание параметров). Это ошибка в
  коде команды: её ловят тесты и gate, читатель её не видит. Первая команда с этим id остаётся.
- `register` замораживает переданное описание параметров.
- `list()` — команды в порядке регистрации; если `enabled` бросает или возвращает не `true`,
  в списке `enabled: false`.

## Ограничения

- Команды синхронные. Долгая работа (подгрузка урока) запускается командой и отражается в
  состоянии; результат `run` говорит только, что команда принята и отработала без исключения.
- Команду нельзя снять с регистрации или заменить.
- В сообщениях id обрезается до 64 знаков, имя лишнего параметра до 40, проблем не больше 20
  (дальше строка «and N more»), текст исключения до 200 знаков.
- Сообщения об ошибках на английском и предназначены разработчику и каналу управления;
  читателю их показывает интерфейс своими словами по `code`.
- Целые числа — только в безопасном диапазоне JavaScript (±2^53).
