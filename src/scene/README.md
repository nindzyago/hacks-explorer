# src/scene — сцена урока

Слой L3 (адаптер). `Scene.svelte` рисует SVG по данным урока (`SiteLesson`) и раскладке
`src/core/scene-layout` (дизайн M1.2 E1). В M1.2a сцена неподвижна: участники, зоны доверия,
линия сообщений; сообщение и его движение по часам плеера — M1.2b.

```svelte
<Scene lesson={siteLesson} />
```

## Поведение

- Ширина сцены — ширина её блока (`bind:clientWidth`); раскладка пересчитывается при изменении.
  `viewBox` равен размеру раскладки, SVG растянут на ширину блока, поэтому прокрутки вбок нет.
- Положения — атрибуты SVG; цвета и шрифты — классы в `<style>` компонента из токенов
  `src/ui/tokens.css`. Атрибута `style=` нет: политика сайта не разрешает встроенные стили.
- Иконки (`icons.ts`) — файлы `content/icons/*.webp`, сборщик кладёт их в `assets/` с хешем в
  имени, адрес того же сайта. Имя иконки из урока (`icon:имя` или id участника) без файла —
  нейтральная заглушка (пунктирная рамка со знаком «?», `data-testid="icon-placeholder"`), не
  битая картинка. Gate отдельно не пускает урок с неизвестной иконкой (`scripts/content.test.mjs`).
- Доступность: `<svg role="img">` с заголовком «Схема урока «…»» и описанием
  (`data-testid="scene-description"`): участники слева направо и состав зон.
- `data-testid`: `scene`, `participant-<id>`, `zone-<id>`, `scene-description`,
  `icon-placeholder`. Части внутри помечены `data-part` (`icon`, `name`, `note`, `frame`, `label`)
  — по ним e2e проверяет, что ничего не выходит за сцену и не накладывается.
- Красный только у опасной зоны (`danger`): рамка `--scene-attack`, подпись `--scene-attack-text`
  (темнее, чтобы мелкий текст держал контраст 4,5:1).

## Ограничения

- Иконки — растровые вырезки 310 × 275 (K42): на экранах высокой плотности при 150 px слегка
  мягкие; на бумаге сцены виден лёгкий квадрат зерна листа вокруг иконки, как в прототипе.
- Нажатий на участников и зоны нет (словарь — M2).
