# src/core/feed — лента событий

Слой L0 (ядро), M1.5, решение K75. Чистые функции: урок, позиция плеера и «доехало ли сообщение
текущего шага» на входе — строки ленты на выходе. Интерфейс — отметки в строках таблицы «Ход
атаки» `src/ui/StepsTable.svelte` (M2.1a, K91: отдельной ленты на странице больше нет).

```ts
feedLines(lesson, { step, defence }, arrived); // FeedLine[]
stepArrived(step, elapsedMs, reducedMotion); // boolean
```

## Поведение

- Лента выводится из состояния плеера, а не копится: строка на каждый шаг текущего режима с
  первого до текущего, новая внизу. Тот же шаг, режим и прибытие дают те же строки, поэтому
  `player.back` возвращает ровно прежнюю ленту (S1), а смена режима сразу показывает ход нового
  режима до того же номера (S2).
- Строка: номер шага в режиме, текст «Кто → Кому: сообщение» (по именам участников; шаг без
  движения — «Кто: сообщение»; неизвестный участник — его id), отметка и слово.
- Отметка: вид сообщения (`legit` «обычное», `attack` «вредное», `safe` «безопасное»),
  `stopped` «остановлено» у шага с пометкой `stopped`, а у текущего шага, пока сообщение в пути, —
  `moving` «в пути». Остановленное сообщение в пути — `moving`, как на сцене оно едет вредным
  (K62).
- `stepArrived`: сообщение доехало, когда прошло `TRAVEL_MS` времени урока; сразу при
  `prefers-reduced-motion` (S11) и у шага, где отправитель и получатель один участник, — как на
  сцене (`travelProgress`).
- Номер шага обрезается как у плеера (`currentStep`): за концом — последний, меньше 1 или NaN —
  первый, дробь вниз. Режим без шагов — пустая лента.
- В таблице (M2.1a): строки до текущей включительно «произошли» и несут отметку (`data-mark`),
  у следующих отметки нет (`data-mark="future"`, «—»). Щит и «остановлено» — только в отметке;
  итог шага показывается как есть, без приставки.

## Текст итога и сообщения (`result.ts`)

- `keepTogether(text)`: пробелы сообщения становятся неразрывными, чтобы «admin' --» не
  разрывалось на телефоне; слишком длинное сообщение всё равно переносится (`overflow-wrap`).

## Переключатель защиты

Подпись «Защита: …» стоит в своём месте постоянной ширины (12.5rem, две строки, при выключенной
защите — «Защита выключена»), поэтому смена режима не сдвигает ни одной кнопки полосы
управления (проверено на 1280, 1024 и 390 px). Длинное имя защиты обрезается на второй строке
«…», полностью — во всплывающей подсказке.

## Ограничения

- Лента не помнит, что читатель уже видел: после «Сначала» в ней одна строка. История
  просмотра — не цель (K75).
- Не больше строк, чем шагов в режиме (≤ 100, `MAX_STEPS`).
