## Часы плеера (`clock.ts`)

Единственный источник времени для анимации (инвариант «Время подменяемо», решение K16). Часы
сами время не читают: миллисекунды им подаёт драйвер реального времени (`src/time`), тест или
канал управления.

```ts
import { createClock } from './clock';

const clock = createClock(); // шаг 10 мс, не больше 1000 шагов за один tick
const off = clock.subscribe((event) => {
  if (event.type === 'step') {
    /* прошёл один шаг: event.timeMs кратно event.stepMs */
  } else {
    /* 'set': время перескочило в event.timeMs, шагов не было */
  }
});

clock.tick(25); // { ok: true, steps: 2 }; 5 мс остались до следующего шага
clock.now(); // 20 — время последнего завершённого шага
clock.snapshot(); // { timeMs: 20, pendingMs: 5, stepMs: 10 } — простые данные для дампа
clock.set(1234); // { ok: true, steps: 0 }; timeMs 1230, pendingMs 4
off();
```

### Поведение

- Время идёт только целыми шагами. Остаток меньше шага копится, поэтому шаги не зависят от того,
  как время нарезано: `tick(100)` и `tick(40)` + `tick(60)` дают одни и те же события.
- Внутри шага подписчик видит `now()` равным времени этого шага и `pendingMs` равным нулю —
  тоже независимо от нарезки.
- `set(ms)` — перемотка: шаги между старым и новым временем не выполняются, подписчики получают
  одно событие `set`. Состояние после перемотки подписчик вычисляет из времени сам.
- Подписчики вызываются в порядке подписки. Отписка действует сразу, даже посреди шага;
  подписавшийся во время события получит следующее. Одна функция, подписанная дважды, — две
  подписки. Событие заморожено: подписчик не может изменить его для следующих.
- `set` и `tick` не бросают исключений. Ответ — `{ ok: true, steps }` или
  `{ ok: false, error: { code, message } }`:

  | code | когда | время изменилось |
  |---|---|---|
  | `invalid-time` | не число, NaN, бесконечность, дробное, отрицательное, больше 2^53 | нет |
  | `tick-too-large` | `tick` больше `maxTickMs` (10 секунд при настройках по умолчанию) | нет |
  | `out-of-range` | время стало бы больше 24 часов (`MAX_TIME_MS`) | нет |
  | `reentrant` | `set` или `tick` вызваны подписчиком изнутри события | нет |
  | `listener-failed` | подписчик бросил исключение | да: все шаги выполнены, остальные подписчики вызваны |

- `createClock` бросает `ClockConfigError`, если `stepMs` или `maxStepsPerTick` не целое
  положительное число в пределах (шаг до 24 часов, шагов до миллиона). Это ошибка в коде.

### Ограничения

- Время — целые миллисекунды. Дробные доли кадра копит драйвер, не часы.
- Часы не знают о паузе и скорости: пауза — это остановленный драйвер, скорость появится в M1.3.
- Отписать всех разом и «сбросить» часы нельзя; новый урок — `set(0)` или новые часы.
- Числа 10 мс, 1000 шагов и 24 часа выбраны без замеров (K16).

## Дамп состояния (`dump.ts`)

`stableDump(value)` — текст JSON с отступом в два пробела и ключами объектов в фиксированном
порядке (по кодам UTF-16, то есть `"10"` раньше `"9"`). Одинаковые данные дают одинаковый текст
байт в байт, в каком бы порядке ни добавлялись ключи. Так сравниваются два прогона сценария.

```ts
const result = stableDump({ state, clock: clock.snapshot() });
if (result.ok) result.text; // строка
else result.error; // { code, path: '$.scene.nodes[3].x', message }
```

- Не бросает исключений. Свойство со значением `undefined` пропускается, как в JSON; ключи-символы
  и неперечислимые свойства не выводятся; `-0` выводится как `0`.
- Всё, что JSON молча исказил бы, — ошибка с путём к значению:

  | code | когда |
  |---|---|
  | `unsupported` | NaN, бесконечность, `undefined` в массиве или на верхнем уровне, дырка в массиве, функция, символ, bigint, Map, Set, Date, Error, экземпляр класса |
  | `cycle` | объект содержит сам себя (одна и та же ссылка в двух местах — не ошибка) |
  | `unreadable` | геттер или прокси бросили исключение |
  | `too-deep` | вложенность больше 64 |
  | `too-large` | больше 100 000 значений |

- Путь в ошибке обрезается до 200 знаков слева. Пределы 64 и 100 000 выбраны без замеров.
- У объектов `toJSON` не вызывается: дамп показывает данные как есть.
