# src/core/cvss — калькулятор CVSS 3.1 (M2.5)

Слой L0, чистые функции. Читает вектор `CVSS:3.1/…` и считает базовую оценку ровно по
спецификации FIRST CVSS v3.1: §6 (строка вектора), §7.1 (формулы), §7.4 (веса), §5 (тяжесть),
приложение A (Roundup на целых числах). Решение K82.

```ts
import { formatScore, scoreCvss31 } from './cvss';

const r = scoreCvss31('CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H');
if (r.ok) formatScore(r.value.score); // '9.8', r.value.severity === 'critical'
else r.error.code; // 'bad-prefix', 'missing-base', …
```

## Поведение

- Вектор строгий: префикс `CVSS:3.1/`, регистр важен, без пробелов, все восемь базовых метрик,
  метрики в любом порядке, ни одна не повторяется (§6). Векторы 3.0 и 4.0 не принимаются.
- Временные и средовые метрики (`E`, `RL`, `RC`, `CR`…`MA`) проверяются по таблице 15 и
  сохраняются в `vector.other`, но не считаются: сайт показывает базовую оценку, как NVD.
- Ничего не бросает. Ошибка — данные `{ code, message }`:

  | code | когда |
  |---|---|
  | `not-a-string` | не строка |
  | `too-long` | длиннее 256 символов (самый длинный верный вектор — 117) |
  | `bad-prefix` | не начинается с `CVSS:3.1/` |
  | `bad-metric` | кусок не вида `AV:N` (пустой, строчные буквы, пробел, лишний `/`) |
  | `unknown-metric` | метрики нет в CVSS 3.1 (`AT`, `XX`, `__proto__`) |
  | `bad-value` | значение не из таблицы (`AV:X`, `AC:M`) |
  | `duplicate` | метрика дважды |
  | `missing-base` | нет хотя бы одной базовой метрики |

- `roundup` — псевдокод приложения A: вход умножается на 100 000 и округляется до целого, дальше
  только целочисленная арифметика. `0.1 + 0.2` даёт 0.3, а не 0.4.
- Тяжесть по таблице 14: 0.0 — `none`, 0.1–3.9 `low`, 4.0–6.9 `medium`, 7.0–8.9 `high`,
  9.0–10.0 `critical`.
- `formatScore` — всегда один знак после точки (`10.0`, `0.0`), точка, как в NVD.

## Оракулы (тесты `cvss.test.ts`)

- R5: 27 разобранных примеров FIRST (`fixtures/first-examples.json`, first.org/cvss/v3.1/examples,
  получено 2026-11-19). Примеры 24 и 31 пропущены: у них по две оценки на одну таблицу.
- R6: девять CVE из NVD с датой и адресом запроса (`fixtures/nvd.json`): шесть названы в каталоге,
  три (POODLE, HTTP/2 Rapid Reset, Spectre v1) добавлены по темам каталога. Тесты в сеть не ходят.
- Все 2592 базовых вектора сверены с независимой точной реализацией на рациональных числах
  (BigInt) прямо в тесте: расхождений нет. Измерено: при нашем порядке вычислений и наивный
  `Math.ceil` на базовых векторах не ошибается; ловушки с плавающей точкой проверены на самом
  `roundup`.

## Где используется

- Проверка урока (`src/core/lesson/parse.ts`): слово паспорта `cvss` принимается, только если
  вектор читается этим модулем; иначе `bad-value` с причиной.
- Панель объяснения (`src/ui/explain.ts`): строка CVSS — «9.8 · критическая», под ней вектор;
  нечитаемый вектор показывается как есть, без оценки.

## Ограничения

- Нет временной и средовой оценки и интерактивного калькулятора (K82).
- Эталонный калькулятор FIRST (`cvsscalc31.js`) как оракул не запускался.
