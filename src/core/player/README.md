# src/core/player — плеер урока

Слой L0 (ядро), M1.3. Чистые функции: состояние плеера и момент часов плеера на входе, новое
замороженное состояние на выходе (тот же объект, если ничего не изменилось). Таймеров нет:
автопроигрывание двигается, только когда `advance` получает более позднее время (K17).

```ts
interface PlayerState {
  step: number;        // номер шага в текущем режиме, с 1
  defence: boolean;    // режим «С защитой»
  startedMs: number;   // время часов, когда начался шаг: отсюда едет сообщение
  playing: boolean;
  speed: 0.5 | 1 | 2;
  counts: { without: number; with: number }; // шагов в каждом режиме; 0 — урок не загружен
}
```

Команды над ним — `src/commands/player.ts` (`player.*`, `defence.*`, `lesson.open`).

## Поведение

- `goto`, `stepForward`, `back`, `setDefence`: шаг начинается заново с текущего времени
  (сообщение едет от отправителя) и пуск выключается. Назад тоже едет: так «назад» возвращает
  ровно то же состояние, что было (S1). За концами ничего не меняется; номер за концом — последний
  шаг, меньше 1 или NaN — первый, дробь округляется вниз. Смена режима держит номер шага (S2) и
  обрезает его по числу шагов нового режима.
- `play`: сообщение в пути доезжает; доехавшее — сразу следующий шаг; на последнем шаге — заново
  с первого. `pause` выключает пуск; сообщение в пути доезжает.
- `advance(state, now)`: шаг длится `stepDurationMs(speed)` = (900 + 1500) / скорость мс (ход
  `TRAVEL_MS` и пауза `PAUSE_MS`, как в прототипе). Следующий шаг начинается ровно на границе,
  поэтому результат не зависит от того, как часто вызывать. На последнем шаге пуск выключается,
  когда сообщение доехало (900 / скорость мс). Без известного числа шагов ничего не делает.
- `elapsedMs(state, now)` = max(0, now − startedMs) × скорость — время урока, по нему сцена ставит
  сообщение. `setSpeed` переносит `startedMs`, чтобы сообщение не прыгнуло (целые мс).
- `needsTime(state, now)`: пуск включён или сообщение в пути. По нему `src/main.ts` включает и
  выключает драйвер реального времени.
- `withCounts`: урок загружен — число шагов (плохие значения → 0, больше 100 → 100), шаг
  обрезается, начало шага сохраняется.

## Ограничения

- Не больше 100 шагов в режиме (`MAX_STEPS`).
- Скорость только 0.5, 1, 2; запоминание в `localStorage` (архитектура §5) — не сделано.
