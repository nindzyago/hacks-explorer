# src/core/sequence-layout — раскладка вида «Последовательность»

Слой L0: чистая функция без DOM (M6.2, дизайн M6 §5, K130). По участникам и шагам урока, режиму
защиты, текущему шагу и ширине — где стоят дорожки и линии жизни, где каждая строка шага, её
разделитель «Шаг N — название», подпись сообщения и стрелка. Рисует `src/scene/Sequence.svelte`.

## API

```ts
import { layoutSequence, rowPaint, rowSign, wrap, clean } from './layout';

const layout = layoutSequence({ participants, steps, defence, step: 3, width: 760 }, t);
layout.lanes[0]; // { id, icon, x, iconBox, name: SequenceText, note: SequenceText | null }
layout.rows[0]; // { number, stepId, from, to, shape: 'arrow' | 'note', kind, stopped, paint,
//   state: 'past' | 'current' | 'future', band, separator, x1, x2, y, label, labelBox }
layout.lifelineTop; layout.lifelineBottom; layout.height; layout.current;

rowPaint(row, arrived); // остановленное — цвет вида в пути, зелёное по прибытии
rowSign(row, arrived); // знак, дублирующий цвет: attack | safe | stopped | right | left | here
```

`t` — переводчик строк интерфейса; ядро называет один ключ `sequence.row` («Шаг {number} —
{title}»). Единицы — CSS-пиксели, viewBox вида ровно `width × height`.

## Правила

- Дорожки — участники в порядке сцены, на равных колонках `(width − 16) / n`. Повтор id — берётся
  первый. Иконка не шире колонки; имя (жирный 12 px) и заметка (11 px) — до двух строк, дальше «…».
- Строки — шаги текущего режима в порядке урока (K20), не больше 100. Шаг между двумя дорожками —
  стрелка; шаг к себе или с неизвестной дорожкой — заметка на той дорожке, что есть (или
  посередине, если нет ни одной).
- Подпись сообщения (жирный 11 px) — над стрелкой, ширина не меньше 168 px (или ширины вида),
  центр над стрелкой, сдвиг внутрь вида; до трёх строк. Слово длиннее строки рвётся после `.`,
  `-`, `/`, `_`, `:`, `=`, `&`, `?`, `,`, `;` во второй половине строки, иначе по краю. Обрезанный
  текст помечен `cut`, полный — в `full` (вид показывает его в `<title>`).
- Все тексты — JetBrains Mono, 0,6 em на знак: ширина строки известна точно. Самый мелкий
  текст — 11 px.
- Враждебный ввод (L0): NaN, отрицательная и огромная ширина (зажимается в 240…4000), шаг вне
  урока (как у плеера), неизвестные участники, пустые и управляющие символы, не-массивы, тысячи
  шагов и десятки участников — раскладка без исключения, все коробки внутри вида
  (`layout.test.ts`).

## Проверки

`layout.test.ts`: все уроки `content/lessons` на двух языках, в обоих режимах, при 320–1000 px —
строка на каждый шаг, состояния, коробки внутри полос, полосы друг под другом; на 760 px ничего
не обрезано, на 366 px не обрезана ни одна подпись. Браузерные — `e2e/sequence.spec.ts`.
