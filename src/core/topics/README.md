# src/core/topics — каталог тем для панели уроков

Слой L0 (M2.1b, решения K112–K114). Все темы справочника — один Markdown-файл на язык:
`content/locales/<язык>/catalog.md` (рядом с `ui.md` и папкой словаря `glossary/`). Модуль проверяет файлы,
даёт сайту данные `data/topics/<язык>.json` и правило поиска панели «Уроки» (сценарий S7).

| Файл | Что делает | Тянет разборщик Markdown |
|---|---|---|
| `file.ts` | `parseCatalogFile`: один файл → разделы и темы или ошибки с файлом и строкой | нет (построчно) |
| `check.ts` | `checkCatalogs`: все языки вместе, уроки в каталоге, каталог у каждого языка сайта | нет |
| `site.ts` | `SiteTopics`, `topicsFile`, `toSiteTopics`, `readSiteTopics` (враждебный ввод) | нет |
| `search.ts` | `normalize`, `filterTopics`, `readyCount`: поиск и счёт «готово N из M» | нет |

## Формат

```markdown
# Каталог уроков

`catalog` ru · `format` 1

## `B` Веб: инъекции

- `B1` SQL-инъекция
- `B8` NoSQL-инъекция — что видно на схеме (необязательно)
```

- Раздел — одна буква A–L, по порядку, каждый один раз, без пустых разделов.
- Тема — буква своего раздела и номер (`B1`…`L5`), каждая один раз; название — простой текст до
  80 знаков; после « — » необязательная строка «что увидите» до 200 знаков.
- Остальные строки — заметки, их не читают. Файл до 64 КБ, тем до 300.

## Правила проверки (gate)

- Русский каталог — основа: в переводе те же разделы и темы в том же порядке; лишняя или
  пропущенная тема — ошибка с номером строки русского файла.
- Каждая папка `content/lessons/<id>` — тема каталога; раздел урока (`section`) совпадает с
  разделом темы.
- У каждого языка из `content/locales/languages.md` есть каталог (K94).
- Урок «готов» на языке, когда есть его файл на этом языке; это решает сборка.

## Поиск

Все слова запроса должны найтись в названии темы, названии её раздела или номере; регистр,
ё/е и знаки препинания не важны; запрос без букв и цифр — пустой. Выбор раздела в панели
очищает запрос и показывает весь раздел (S7); запрос, набранный после выбора, ищет внутри
раздела. Порядок — порядок каталога. Запрос режется до 100 знаков. Поиск и раздел живут, пока
панель открыта: смена вкладки их хранит, закрытие панели сбрасывает.
