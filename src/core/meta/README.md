# src/core/meta — заголовок и описание страницы (M4.3)

Слой L0. `meta.ts` делает заголовок и описание страницы урока из данных урока и строк `ui.md`;
им пользуются и сборка (статические страницы `scripts/site-pages.ts`, их читают превью ссылок и
поисковики без скриптов), и сайт (`src/ui/App.svelte`), поэтому оба говорят одно и то же.

- `pageTitle(name)` — `<название> — Hacks Explorer`; без названия — только имя проекта.
- `lessonDescription(passport, say)` — шаблон `meta.lesson.description` из `ui.md` языка:
  класс атаки, к чему ведёт, как защититься (поля паспорта `class`, `impact`, `defence`).
  Нет хотя бы одного поля — `null`, страница берёт `app.description`. Точка в конце поля не
  удваивается; первое слово защиты пишется со строчной, если это обычное слово с заглавной
  («Обновить», «Update»), а аббревиатуры и имена с цифрами остаются («HTTPS», «CSRF-токен»,
  «Log4j»). Имя собственное в начале защиты («Apache …») стало бы строчным — в уроках такого нет.
- Описание — одна строка, не длиннее 250 знаков (обрезка по слову с «…»): враждебный урок не
  сделает огромное.

## Статические страницы, sitemap, карточки

- Сборка пишет `<язык>/lesson/<ID>.html` и `<язык>/about.html` — тот же index.html со своим
  `<html lang>`, `<title>`, описанием, canonical, hreflang (каждый язык сайта и `x-default` =
  первый язык), Open Graph и Twitter card. Cloudflare отдаёт `/ru/lesson/K1` из
  `ru/lesson/K1.html` (`assets.html_handling: auto-trailing-slash` в `wrangler.jsonc`), любой
  другой путь — index.html, как раньше. `scripts/serve-static.mjs` повторяет это для e2e.
- index.html получает Open Graph сайта без canonical: он отвечает на любой неизвестный путь.
- `sitemap.xml` — все страницы выше со ссылками на версии на других языках; `robots.txt`
  указывает на него. Адрес сайта — одна константа сборки `SITE_ORIGIN` (`scripts/site-pages.ts`); в коде сайта адресов чужих серверов нет (structure-check).
- Карточки 1200×630 лежат в `public/cards/<ID>.<язык>.png` и `about.<язык>.png`, рисуются
  `npm run cards` (ImageMagick) и коммитятся; в каждой — хеш того, из чего она нарисована.
  Gate (`scripts/cards.test.ts`) падает, если карточки нет, она устарела или тяжелее 100 КБ.
  Страница без своей карточки при сборке получает карточку сайта.
- Канонический адрес на странице не меняется, когда читатель уходит на другой урок внутри
  приложения: поисковик открывает каждый адрес заново и видит свой.
