# src/core/glossary — словарь терминов

Слой L0 (M2.4, K7; разбит на файлы в G17, K133). Словарь — папка на язык:
`content/locales/<язык>/glossary/` (рядом с `ui.md` из M2.3). В ней `index.md` — заголовок и
список разделов — и по файлу на раздел: `web.md`, `basics.md`, … Модуль проверяет папку целиком,
находит термины в тексте уроков при сборке и даёт сайту данные. Сайт текст не ищет (K31): он
получает готовые узлы `term`.

| Файл | Что делает | Тянет разборщик Markdown |
|---|---|---|
| `check.ts` | `checkGlossaries`: файлы словаря → данные или ошибки с файлом и строкой | да (только сборка) |
| `match.ts` | правило поиска: `createMatcher`, `linkTerms` | нет |
| `build.ts` | словарь → файлы сайта; урок → урок со ссылками на термины | нет |
| `site.ts` | `SiteGlossary`, `glossaryFile`, `readSiteGlossary` (враждебный ввод), пределы сайта | нет |
| `words.ts` | слова файлов на каждом языке: `Словарь`, `Разделы`, `Формы` | нет |

## Файлы папки

```
content/locales/ru/glossary/
  index.md        # Словарь, строка словаря, ## Разделы
  basics.md       # термины раздела basics
  web.md          # термины раздела web
  web.2.md        # продолжение web, когда web.md подходит к 64 КБ (до web.9.md)
```

- Имя файла раздела — id раздела из `index.md`; продолжения `<раздел>.2.md` … `<раздел>.9.md`
  идут после `<раздел>.md` по номеру. Других файлов в папке нет. Раздел без файла — раздел без
  терминов.
- Порядок терминов — разделы по порядку `index.md`, внутри раздела файлы по номеру, внутри файла
  сверху вниз. Сайт показывает список по разделам и по алфавиту, поэтому порядок важен только для
  кусков данных сайта и сверки перевода.
- Новый термин — секция `## `id` Название` в файле своего раздела. Термин переезжает в другой
  раздел вместе со строкой `category` и файлом.

## Формат на примере

`index.md`:

````markdown
# Словарь

`glossary` ru · `format` 2

## Разделы

- `web` Веб и базы данных
- `basics` Основы
````

`web.md`:

````markdown
# Веб и базы данных

`glossary` ru · `category` web

## `sql-injection` SQL-инъекция

`category` web · `see` injection, parameterized-query · `lessons` B1

Формы: SQL-инъекция, SQL-инъекции, SQL-инъекцию, SQL-инъекцией, SQL-инъекций

Инъекция в запрос к базе данных: сервер вклеивает присланный текст в SQL-запрос…
````

`basics.md`:

````markdown
# Основы

`glossary` ru · `category` basics

## `attacker` Атакующий

`category` basics · `see` victim · `lessons` B1, I1

Тот, кто пытается заставить систему работать не по правилам…
````

| Часть | Как пишется | Обязательно |
|---|---|---|
| Заголовок `index.md` | `# Словарь` (на языке файла) | да |
| Строка словаря `index.md` | `` `glossary` ru · `format` 2 ``, язык равен имени папки языка | да |
| Разделы | в `index.md`: `## Разделы`, список `` - `id` Подпись ``; id не `index` | да, сразу после строки словаря; терминов в `index.md` нет |
| Заголовок файла раздела | `# Подпись` — подпись раздела из `index.md` | да |
| Строка файла раздела | `` `glossary` ru · `category` web ``, раздел равен имени файла | да |
| Термин | `## `id` Название` — id из строчных латинских букв, цифр и дефиса | — |
| Служебная строка | `` `category` id `` обязательно и равен разделу файла; `` `see` id, id `` и `` `lessons` B1, I1 `` по желанию; `see` называет термин любого файла | да |
| Формы | `Формы: форма, форма, …` — слова, как они стоят в тексте; без строки термин в тексте не ищется (его открывают схема и «см. также») | нет |
| Определение | абзацы и списки, **жирный**, *курсив*, `код` — как текст урока; до 700 знаков | да |

Ссылок, HTML и картинок нет нигде в файлах. Адреса и домены — только учебные (L4.2), как в уроках.

### Пределы

| Что | Предел | Почему |
|---|---|---|
| Один файл папки | 64 КБ, 1000 строк (пределы файла урока) | враждебный pull request; один файл раздела — около 100 терминов, дальше `web.2.md` |
| Терминов в языке, во всех файлах | 600 (`MAX_GLOSSARY_TERMS`, `site.ts`) | 75 уроков по оценке G17 — 300–450 терминов; столько же принимает сайт |
| Файлов в папке языка | 200 | 20 разделов × 9 файлов и `index.md` |
| Разделов | 20 | |
| Формы | 40 у термина, до 60 знаков в форме и в названии | |
| Определение | 700 знаков | |

Предел терминов считается по заголовкам `##` до разбора терминов: файл, на котором сумма
переходит 600, получает ошибку `too-large` на строке 601-го термина, и термины не разбираются.

### Проверка (`npm run content`, сборка, gate)

Ошибка — данные `{ file, line, column, path, code, message }`, как у уроков (общий `report.ts`);
`file` — тот файл папки, где ошибка. Не больше 100 ошибок на файл.

| code | когда |
|---|---|
| `bad-path`, `unknown-language` | файл не `index.md`, не `<раздел>.md` и не `<раздел>.<2–9>.md`; раздела нет в `index.md`; старый `content/locales/<язык>/glossary.md` (сообщение называет новую папку); языка нет в `words.ts` |
| `too-large`, `too-complex`, `too-deep` | пределы выше; `too-large` у самой папки — больше 200 файлов |
| `missing-title`, `bad-header`, `missing-section` | нет `# Словарь` или `# Подпись раздела`, строки словаря или `## Разделы` |
| `stray-content` | термин в `index.md`; текст до первого термина в файле раздела |
| `bad-line`, `unknown-word`, `bad-value` | служебная строка не того вида; неизвестное слово; неверный id; раздел не из списка; термин лежит в файле чужого раздела (сообщение называет нужный файл); форма — не слова (`запрос.*`, `[аы]`, `|`) |
| `duplicate` | термин, раздел, форма, `see` или урок повторяются — во всей папке языка; второй термин называет первый `файл:строка`; форма у двух терминов из любых файлов |
| `unknown-term` | `see` называет термин, которого нет ни в одном файле языка; `term:` участника или зоны урока — тоже (ошибка в файле урока) |
| `unknown-lesson` | `lessons` называет урок, которого нет в `content/lessons` |
| `html`, `image`, `link`, `not-allowed`, `empty-section` | запрещённое в тексте; NUL и невидимые знаки направления текста (U+202A–U+202E, U+2066–U+2069) в любом месте любого файла; термин без определения |
| `address` | IP или домен вне учебных (правило уроков, с M2.8 и IPv4 числом) |
| `unknown-id` | CWE, техника ATT&CK, пункт OWASP или CVE в тексте не из проверенных списков `src/core/lesson/ids.ts` (M2.8, K86) |
| `missing-glossary` | у языка уроков или сайта нет `glossary/index.md` (K94); русский нужен всегда, когда есть уроки |
| `translation-mismatch` | перевод расходится с русским: разделы `index.md`; набор файлов; в каждом файле id терминов по порядку, `category`, `see`, `lessons`. Ошибка в файле перевода, на термине или на строке 1 файла, которого не хватает или который лишний |

## Правило поиска терминов (`match.ts`)

Сборка (`scripts/lesson-data.ts`) ищет термины в трёх уровнях каждого шага и в «Как защититься»,
сайт получает `{ type: 'term', id, children }`:

1. Ищутся только формы из строки «Формы», никаких шаблонов. Русские падежи перечисляются.
2. Регистр не важен, «ё» равна «е». Пробел в форме совпадает с одним пробелом или переносом
   строки.
3. Только целые слова: вокруг формы нет букв, цифр, `_` и `-`. Поэтому `SQL` не находится в
   `SQL-инъекция` и `SQL-запрос` — такие слова пишутся отдельными формами.
4. Где начинаются формы нескольких терминов, побеждает самая длинная; найденный текст
   пропускается целиком, внутри него короче не ищется.
5. Один термин — одна ссылка на блок (абзац или весь список), на первом вхождении.
6. Код не ищется: ни `код в строке`, ни блоки кода. Внутри **жирного** и *курсива* ищется, через
   их край — нет; знаки сразу за краем считаются для целых слов: в `**SQL**-инъекция` слово `SQL`
   не находится.
7. В определении термин не ссылается сам на себя; на другие термины ссылается.

## Данные сайта

Два вида файлов на язык (CI3), оба грузятся при первом открытом термине или вкладке «Словарь»
(`src/services/glossary`), не при открытии страницы:

| Файл | Что в нём | Зачем |
|---|---|---|
| `data/glossary/<язык>.json` — оглавление (`SiteGlossary`) | разделы; у каждого термина `id`, название, раздел и номер куска; список хешей кусков | список и поиск во вкладке, названия «см. также», подпись раздела |
| `data/glossary/<язык>.<hash8>.json` — кусок (`SiteGlossaryChunk`) | подряд идущие термины: определение (дерево узлов со ссылками), `see`, уроки `{ id, title }` | определение открытого термина |

Сборка (`splitSiteGlossary`) кладёт термины по порядку словаря (разделы, файлы, термины) в
куски и закрывает кусок, пока он не перерос `GLOSSARY_CHUNK_BYTES` (16 КБ); один термин всегда
меньше. Оглавление называет кусок хешем его текста, поэтому старое оглавление не сойдётся с куском
другой сборки. Сайт читает кусок как враждебный ввод: в нём ровно термины этого куска по
оглавлению, в том же порядке, `see` — термины оглавления. Форм нет нигде. Кусок больше 30 КБ —
ошибка сборки и `npm run budget`.

Растёт только оглавление: около 84 байт на термин (57 терминов ru — 4,8 КБ). Его предел — 60 КБ
(`MAX_GLOSSARY_INDEX_BYTES`, G17): 600 терминов с обычными названиями — около 50 КБ, в gzip около
12 КБ. Длинные названия у всех терминов могут его переполнить — тогда сборка падает с сообщением
про оглавление, на строке 1 `index.md`.

## Ограничения

- Формы перечисляются руками: незнакомая форма слова не найдётся (это выбор, а не ошибка:
  лишняя ссылка хуже пропущенной).
- Термин через край жирного (`**база** данных`) не находится.
- Одно слово — один термин: «запрос» значит и HTTP-запрос, и запрос к базе, поэтому
  определение общее.
- Подпись раздела пишется дважды: в `index.md` и заголовком файла раздела; проверка требует,
  чтобы они совпадали.
- Оглавление сайта одно на язык; если терминов станет больше 600, нужно делить уже его
  (например, по разделам), а не только исходник.
