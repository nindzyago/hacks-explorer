# Hacks Explorer

Как устроены атаки и как от них защититься: интерактивный справочник по компьютерной
безопасности для новичков. Каждый урок — одна атака на вымышленную систему, показанная по шагам
на схеме. Включите защиту и посмотрите, как та же атака не проходит. Каждый шаг объяснён на трёх
уровнях: «Просто», «По шагам», «Глубже».

[English version](README.md)

Сайт: https://hacks.antipic.com

## Откуда идея

Жанр взят у [Protocol Explorer](https://protocol-explorer-alpha.vercel.app): один экран со
схемой, списком шагов, панелью объяснения, кнопками пуска и шага. Hacks Explorer применяет эту
идею к атакам и защите. Дизайн, код, уроки и картинки свои; из Protocol Explorer и других
закрытых ресурсов ничего не копируется (см. «Что мы не принимаем» в
[CONTRIBUTING.md](CONTRIBUTING.md)).

## Что внутри

- Уроки на русском и английском. Каждый урок есть на каждом языке сайта, иначе сборка не
  проходит.
- У каждой атаки: режим без защиты и с защитой, раздел «Как защититься» и список открытых
  источников (OWASP, MITRE, NVD, RFC и подобные).
- Словарь: термины в тексте урока открывают короткое определение.
- Никакой слежки: нет аналитики, кук, внешних шрифтов и скриптов, запросов к чужим серверам.
- Работает с клавиатуры и на телефоне.

Учим понимать, а не взламывать: уроки показывают механизм на вымышленной системе, только с
учебными адресами (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, 2001:db8::/32, `*.example`).
Готовых к запуску эксплойтов и инструкций против настоящих продуктов нет.

## Запуск у себя

Нужен Node.js 22 или новее.

```sh
npm ci          # поставить зависимости
npm run dev     # сайт на http://localhost:5173
npm run gate    # единственная проверка: формат, линт, типы, тесты, структура, сборка, браузер
```

`npm run content` проверяет только уроки, словари и строки интерфейса — самый быстрый способ
проверить урок, который вы пишете.

## Как устроено

Статический сайт (Svelte и TypeScript, сборка Vite). Урок — данные, а не код: один
Markdown-файл на язык, `content/lessons/<id>/<язык>.md`. Сборка проверяет каждый урок и
превращает его в JSON для сайта; сломанный урок останавливает сборку с
`файл:строка:столбец: сообщение`.

| Путь | Что |
|---|---|
| `content/lessons/` | уроки: папка на урок, файл на язык |
| `content/locales/` | строки интерфейса, словарь и список тем каждого языка; список языков сайта |
| `content/icons/` | иконки участников |
| `src/core/` | формат урока, проверка, плеер; без интерфейса |
| `src/ui/`, `src/scene/` | страница и схема |
| `docs/` | как мы работаем, решения, шаблон урока, инструкция по новому языку |
