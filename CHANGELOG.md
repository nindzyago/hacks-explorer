# Изменения

Здесь записано, что вошло в каждый выпуск. Раздел версии становится описанием GitHub Release:
тег `vX.Y.Z` берёт раздел `## X.Y.Z` (`scripts/release.mjs`, `docs/deploy.md`). Перед тем как
поставить тег, в заголовке раздела «готовится» меняется на дату выпуска.

## 0.1.1 (2026-11-19)

Первый выпуск с GitHub Release. Тег `v0.1.0` поставлен на тот же сайт, но его проверка не
уложилась в лимит 15 минут, и Release не создался; лимит поднят до 30 минут.

Первый выпуск: десять уроков на русском и английском (K120).

### Уроки

- SQL-инъекция (B1), отражённый XSS (C1), CSRF (C4), чужие данные по номеру — IDOR (D1), хеш и
  соль (F1), человек посередине (G1), шифровальщик (H2), фишинг (I1), prompt injection (J1),
  Log4Shell (K1).
- Каждый урок сверен с открытыми источниками (MITRE, OWASP, NVD, CISA, RFC).

### Как устроен урок

- Атака показана по шагам на схеме: участники, зоны, сообщение движется между ними.
- Плеер: шаги вперёд и назад, пуск, пауза, скорость, клавиатура.
- Переключатель «Без защиты / С защитой» и лента событий.
- Объяснение на трёх уровнях глубины, паспорт урока, список открытых источников.
- Словарь терминов: определение всплывает прямо в тексте урока.
- Калькулятор CVSS 3.1.

### Сайт

- Один экран: схема и лента вместе; выдвижная панель с уроками по разделам, поиском и словарём.
- Ссылка ведёт на урок, шаг и режим защиты.
- Русский и английский: язык в адресе, выбор по браузеру, переключатель.
- Телефоны от 360 px; клавиатура, экранные читалки, отключённая анимация (WCAG 2.2 AA по axe).
- Страница «О проекте», своя карточка для соцсетей у каждого урока, sitemap.
- Адрес сайта: https://hacks.antipic.com.
- Никакой слежки: нет аналитики, кук, внешних шрифтов и скриптов; шрифты раздаёт сам сайт.

### Для авторов и участников

- Урок — один Markdown-файл на язык; проверка уроков, словаря и переводов в gate.
- Одна проверка `npm run gate`: формат, линт, типы, модульные и браузерные тесты, структура,
  сборка, размер загрузки, лицензии зависимостей и ассетов.
- Сайт выкладывается сам: Cloudflare Workers Builds, предпросмотр каждого pull request, выпуск по
  тегу с откатом на прошлый тег.
