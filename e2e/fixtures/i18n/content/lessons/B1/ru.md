### `pass` Пропуск

`server → db` · `attack` · `without-defence`
Сообщение: склеенный запрос · Итог: атака прошла

```sql

```

#### Просто

Сайт пропускает вредный запрос.

#### По шагам

Сайт склеивает запрос с текстом формы.

#### Глубже

Склеенный запрос меняет смысл.

### `block` Отказ

`server → db` · `attack` · `with-defence` · `stopped`
Сообщение: запрос с параметром · Итог: остановлено

```sql

```

#### Просто

Сайт не даёт тексту стать командой.

#### По шагам

Сайт передаёт текст отдельно от запроса.

#### Глубже

Параметр не меняет смысл запроса.
