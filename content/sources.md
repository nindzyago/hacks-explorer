# Источники

Ссылки в разделе «Источники» урока ведут только на эти домены и их поддомены
(`cwe.mitre.org` подходит под `mitre.org`). Только `https`. Список расширяется через pull
request: одна строка — домен в обратных кавычках и кто за ним стоит.

- `owasp.org` OWASP
- `mitre.org` MITRE: CWE, CVE, ATT&CK
- `nvd.nist.gov` NVD
- `pages.nist.gov` NIST: SP 800-63 (цифровая идентичность)
- `rfc-editor.org` RFC Editor
- `first.org` FIRST: CVSS, EPSS
- `cisa.gov` CISA
- `w3.org` W3C
- `whatwg.org` WHATWG
- `developer.mozilla.org` MDN
- `logging.apache.org` Apache Logging Services: бюллетени безопасности Log4j
- `cve.org` CVE Program: записи CVE, словарь и порядок работы программы
- `csrc.nist.gov` NIST Computer Security Resource Center: словарь терминов
- `wi-fi.org` Wi-Fi Alliance: программы сертификации Wi-Fi (WPA3, защищённые служебные кадры)
- `openssl.org` OpenSSL: бюллетени безопасности библиотеки OpenSSL
- `learn.microsoft.com` Microsoft Learn: бюллетени безопасности Microsoft (Security Bulletins)
- `signal.org` Signal: спецификации протоколов X3DH и Double Ratchet
- `cwiki.apache.org` Apache Software Foundation: бюллетени безопасности Apache Struts (S2-045, S2-046)
- `struts.apache.org` Apache Struts: объявления о выпусках и документация
- `gao.gov` U.S. Government Accountability Office: отчёты о расследованиях (GAO-18-559, утечка Equifax)
- `openwall.com` Рассылка oss-security: первое сообщение об уязвимостях открытых программ (бэкдор в xz, CVE-2024-3094)
