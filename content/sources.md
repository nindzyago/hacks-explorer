# Источники

Ссылки в разделе «Источники» урока ведут только на эти домены и их поддомены
(`cwe.mitre.org` подходит под `mitre.org`). Только `https`. Список расширяется через pull
request: одна строка — домен в обратных кавычках и кто за ним стоит.

- `owasp.org` OWASP
- `mitre.org` MITRE: CWE, CVE, ATT&CK
- `nvd.nist.gov` NVD
- `pages.nist.gov` NIST: SP 800-63 (цифровая идентичность)
- `rfc-editor.org` RFC Editor
- `first.org` FIRST: CVSS, EPSS
- `cisa.gov` CISA
- `w3.org` W3C
- `whatwg.org` WHATWG
- `developer.mozilla.org` MDN
- `logging.apache.org` Apache Logging Services: бюллетени безопасности Log4j
