# Сеть

`glossary` ru · `category` network

## `mitm` Человек посередине

`category` network · `see` arp, tls, attacker · `lessons` G1, G2, G3, L4

Формы: человек посередине, человека посередине, man-in-the-middle, MITM

Атака, при которой атакующий встаёт между двумя сторонами разговора: обе думают, что говорят друг
с другом, а на деле всё идёт через него. Он может читать и менять сообщения. В MITRE ATT&CK это
техника T1557 «Adversary-in-the-Middle». Защищает шифрование с проверкой собеседника, например TLS.

## `router` Роутер

`category` network · `see` arp, mitm · `lessons` G1

Формы: роутер, роутера, роутеру, роутером, роутере, роутеры, маршрутизатор, маршрутизатора

Устройство, через которое компьютеры локальной сети выходят в другие сети, например в интернет.
Чтобы отправить что-то наружу, компьютер отдаёт пакет роутеру своей сети.

## `arp` ARP

`category` network · `see` router, mitm · `lessons` G1

Формы: ARP, ARP-таблица, ARP-таблицу, ARP-таблице, ARP-таблицы, ARP-запрос, ARP-запроса, ARP-ответ, ARP-ответа, ARP-ответы

Address Resolution Protocol (RFC 826): по IP-адресу соседа в той же сети узнаёт его физический
MAC-адрес. Компьютер спрашивает всех и запоминает ответ в ARP-таблице. Кто отвечает, ARP не
проверяет, поэтому поддельный ответ может выдать атакующего за роутер.

## `tls` TLS

`category` network · `see` certificate, hsts, mitm · `lessons` G1, G3, K2, L3

Формы: TLS, HTTPS

Transport Layer Security — протокол защищённого соединения; HTTPS — это HTTP поверх TLS. Он
шифрует данные и проверяет сервер по сертификату, поэтому тот, кто стоит посередине, не может ни
прочитать, ни незаметно подменить разговор. Текущая версия TLS 1.3 описана в RFC 8446.

## `certificate` Сертификат

`category` network · `see` tls, domain · `lessons` G1, L2, L3, L4

Формы: сертификат, сертификата, сертификату, сертификатом, сертификате, сертификаты, сертификатов

Электронный документ, который связывает имя сайта с его открытым ключом и подписан центром
сертификации. Браузер проверяет, что сертификат выдан на тот домен, который открыт в браузере,
и подписан тем, кому браузер доверяет. Сертификат говорит, чей это сайт, но не говорит, что сайт честный.

## `hsts` HSTS

`category` network · `see` tls, certificate · `lessons` G1, G3, L4

Формы: HSTS, Strict-Transport-Security

HTTP Strict Transport Security (RFC 6797): заголовок, которым сайт велит браузеру ходить к нему
только по HTTPS. Браузер сам меняет `http` на `https` и не даёт пройти мимо ошибки сертификата.
Первый визит защищает список предзагрузки HSTS в браузерах.

## `certificate-authority` Центр сертификации

`category` network · `see` certificate, digital-signature · `lessons` L2, L3

Формы: центр сертификации, центра сертификации, центру сертификации, центром сертификации, центре сертификации, центры сертификации, центров сертификации, корневой центр, корневого центра, корневым центром, корневые центры

Организация, которая проверяет, что заявитель управляет доменом, и подписывает его сертификат.
Браузер доверяет нескольким корневым центрам из своего списка, а через них — всем, кому они
выдали сертификаты по цепочке.

## `forward-secrecy` Прямая секретность

`category` network · `see` tls, key-pair · `lessons` L3, L5

Формы: прямая секретность, прямой секретности, прямую секретность, прямой секретностью, forward secrecy

Свойство защищённого соединения: ключ каждого сеанса разовый и потом стирается. Даже если позже
украдут постоянный ключ сервера, записанные раньше разговоры им не расшифровать. В TLS 1.3 она
есть всегда (RFC 8446).

## `e2e-encryption` Сквозное шифрование

`category` network · `see` encryption, key-fingerprint · `lessons` L5

Формы: сквозное шифрование, сквозного шифрования, сквозному шифрованию, сквозным шифрованием, сквозном шифровании, end-to-end

Шифрование от устройства отправителя до устройства получателя. Сервер передаёт сообщение, но
ключей у него нет, поэтому прочитать его он не может. Кому и когда пришло сообщение, сервер при
этом знает.

## `key-fingerprint` Отпечаток ключа

`category` network · `see` e2e-encryption, key-pair · `lessons` L5

Формы: отпечаток ключа, отпечатка ключа, отпечатку ключа, отпечатком ключа, отпечатке ключа, отпечатки ключей, отпечатков ключей

Короткая запись открытого ключа: цифры или QR-код. Два человека сверяют отпечатки при встрече и
так убеждаются, что сервер не подменил ключ собеседника.

## `network-segmentation` Сегментация сети

`category` network · `see` ransomware, trust-boundary · `lessons` H2

Формы: сегментация сети, сегментации сети, сегментацию сети, сегментацией сети, сегментация, сегментацию, сегментацией

Деление сети на части с правилами, кто к кому может обращаться. Рабочие компьютеры не видят все
серверы, поэтому заражение одной машины не расходится по всей компании.

## `dos` Отказ в обслуживании

`category` network · `see` cia-triad · `lessons` A5, G4

Формы: отказ в обслуживании, отказа в обслуживании, отказе в обслуживании, DoS, DDoS

Атака на доступность: сервис перегружают или ломают так, что законные пользователи не
могут им пользоваться. Если запросы идут сразу с тысяч адресов, это распределённая атака,
DDoS.

## `reverse-proxy` Обратный прокси

`category` network · `see` web-server, request-smuggling · `lessons` E1

Формы: обратный прокси, обратного прокси, обратным прокси, прокси

Программа перед серверами сайта: принимает запросы из интернета и пересылает их серверам, часто
по общим постоянным соединениям. Так устроены балансировщики нагрузки и CDN. Прокси и сервер
должны одинаково понимать границы запросов, иначе возможна контрабанда запросов.

## `cloud-metadata` Служба метаданных облака

`category` network · `see` ssrf, trust-boundary · `lessons` D8

Формы: служба метаданных, службы метаданных, службе метаданных, службу метаданных, метаданные облака

Служба внутри облака, которая отвечает виртуальной машине, что это за машина, и выдаёт ей
временные ключи доступа к облаку. Доступна только с самой машины, по особому адресу. Через SSRF
атакующий заставляет сервер спросить её и забирает ключи; в MITRE ATT&CK это подтехника
T1552.005.

## `evil-twin` Злой двойник

`category` network · `see` mitm, pmf · `lessons` G6

Формы: злой двойник, злого двойника, злому двойнику, злым двойником, злом двойнике, evil twin

Поддельная точка доступа Wi-Fi с тем же именем, что у настоящей сети, часто с более сильным
сигналом. Устройства подключаются к ней, и атакующий оказывается посередине. В MITRE ATT&CK это
подтехника T1557.004 «Evil Twin».

## `pmf` PMF

`category` network · `see` evil-twin · `lessons` G6

Формы: PMF, защищённые служебные кадры, защищённых служебных кадров, защита служебных кадров, защиты служебных кадров

Protected Management Frames, защищённые служебные кадры Wi-Fi (поправка IEEE 802.11w). Команды
вроде «отключись» защищены ключом соединения между устройством и его точкой доступа, и
подделку устройство отбрасывает. В сетях WPA3
обязательны.

## `bgp` BGP

`category` network · `see` autonomous-system, rpki, router · `lessons` G7

Формы: BGP, BGP-4

Border Gateway Protocol (RFC 4271): протокол, которым сети интернета сообщают друг другу, какие
адреса у кого и какой дорогой к ним идти. Сам BGP не проверяет, что сеть владеет адресами,
которые объявляет.

## `autonomous-system` Автономная система

`category` network · `see` bgp · `lessons` G7

Формы: автономная система, автономной системы, автономную систему, автономной системой, автономные системы, автономных систем

Сеть под единым управлением, например провайдер или крупная компания, со своим номером (ASN).
Такие сети обмениваются маршрутами по BGP.

## `rpki` RPKI

`category` network · `see` bgp, certificate · `lessons` G7

Формы: RPKI, ROA

Resource Public Key Infrastructure (RFC 6480): реестр подписанных записей о том, кому выданы
адреса. Запись ROA говорит, какой номер сети может объявлять диапазон. Провайдеры сверяют с ней
анонсы BGP и отбрасывают чужие (RFC 6811).

## `egress-filtering` Фильтрация исходящего трафика

`category` network · `see` c2, network-segmentation · `lessons` H3, K6

Формы: фильтрация исходящего трафика, фильтрации исходящего трафика, фильтрацию исходящего трафика, исходящий трафик, исходящего трафика, исходящие соединения, исходящих соединений

Правила на выходе из сети: компьютеры и серверы могут соединяться только с теми адресами,
которые нужны для работы. Так захваченная машина не дозвонится до сервера атакующего.

## `dns` DNS

`category` network · `see` dns-resolver, dns-poisoning, domain · `lessons` G2

Формы: DNS, DNS-сервер, DNS-сервера, DNS-серверу, DNS-сервером, DNS-запрос, DNS-запросы, DNS-вопрос, DNS-ответ

Domain Name System — система имён интернета: по имени сайта, например bank.example, она выдаёт
его числовой адрес. Вопросы и ответы обычно идут по UDP одним пакетом. Сам по себе DNS ответы не
подписывает; подписи добавляет DNSSEC.

## `dns-resolver` Резолвер

`category` network · `see` dns, dns-poisoning · `lessons` G2

Формы: резолвер, резолвера, резолверу, резолвером, резолвере, резолверы, резолверов

Сервер DNS, который ищет адреса по поручению клиентов: спрашивает другие серверы и запоминает
ответы в кеше на срок, указанный в ответе. Обычно резолвер держит провайдер или компания, и им
пользуются тысячи устройств сразу.

## `dns-poisoning` Отравление DNS

`category` network · `see` dns-resolver, dnssec, mitm · `lessons` G2

Формы: отравление DNS, отравления DNS, отравлению DNS, отравлением DNS, отравление кеша, отравления кеша

Атака, при которой резолвер принимает поддельный ответ и запоминает неверный адрес сайта. Все
его клиенты попадают на сервер атакующего. В MITRE CAPEC это CAPEC-142 «DNS Cache Poisoning».
Защищают случайные номер и порт запроса (RFC 5452) и DNSSEC.

## `dnssec` DNSSEC

`category` network · `see` dns, dns-poisoning · `lessons` G2

Формы: DNSSEC

DNS Security Extensions (RFC 4033): цифровые подписи к ответам DNS. Резолвер проверяет, что
данные пришли от владельца зоны и не изменены. Шифрования DNSSEC не даёт: он защищает
подлинность ответа, а не тайну вопроса.

## `ssl-stripping` SSL stripping

`category` network · `see` hsts, downgrade-attack, mitm · `lessons` G3

Формы: SSL stripping, срезание SSL

Атака посредника, который говорит с сайтом по HTTPS, а с жертвой по обычному HTTP и меняет в
страницах `https` на `http`. Шифрование не взламывается, а убирается с участка до жертвы.
Защищает HSTS со списком предзагрузки.

## `downgrade-attack` Атака понижения версии

`category` network · `see` ssl-stripping, tls · `lessons` G3

Формы: понижение версии, понижения версии, понижению версии, понижением версии, понизить версию, атака понижения

Атака, при которой посредник заставляет стороны договориться о более старой и слабой версии
протокола. В MITRE ATT&CK это техника T1689 «Downgrade Attack». Защищает запрет старых версий:
SSL 3.0 запрещён в RFC 7568, TLS 1.0 и 1.1 — в RFC 8996.

## `tcp-handshake` Рукопожатие TCP

`category` network · `see` syn-flood, port · `lessons` G4, G5

Формы: рукопожатие TCP, рукопожатия TCP, тройное рукопожатие, тройного рукопожатия, SYN-ACK

Три сообщения, которыми открывается соединение TCP (RFC 9293): SYN «хочу соединиться», SYN-ACK
«согласен», ACK «подтверждаю». Пока последнее не пришло, соединение полуоткрыто и занимает место
в очереди сервера.

## `syn-flood` SYN flood

`category` network · `see` tcp-handshake, syn-cookies, dos · `lessons` G4

Формы: SYN flood, SYN-флуд, SYN-флуда, SYN-флудом

Атака на отказ в обслуживании: поток SYN с поддельных адресов забивает очередь полуоткрытых
соединений, и настоящих клиентов сервер уже не принимает (RFC 4987). В MITRE ATT&CK она
описана в подтехнике T1499.001 «OS Exhaustion Flood».

## `syn-cookies` SYN cookies

`category` network · `see` syn-flood, tcp-handshake · `lessons` G4

Формы: SYN cookies, SYN cookie

Защита от SYN flood: сервер ничего не запоминает при получении SYN, а прячет нужные данные в
порядковом номере своего ответа SYN-ACK. Место в памяти выделяется, только когда клиент вернёт
верное число в ACK (RFC 4987).

## `amplification` Усиление

`category` network · `see` ip-spoofing, dos · `lessons` G4

Формы: усиление, усиления, усилению, усилением, усилении, отражённая атака, отражённой атаки, отражённых атак

Отражённая атака на отказ в обслуживании: атакующий шлёт серверам короткие вопросы с адресом
жертвы вместо своего, и большие ответы летят жертве. По данным CISA, DNS усиливает поток в
28–54 раза, NTP — примерно в 557 раз. В MITRE ATT&CK это подтехника T1498.002.

## `ip-spoofing` Подделка адреса отправителя

`category` network · `see` amplification, syn-flood · `lessons` G4

Формы: подделка адреса, подделки адреса, подделку адреса, подделкой адреса, поддельный адрес, поддельного адреса, поддельных адресов, поддельные адреса

Пакет, в котором вместо настоящего адреса отправителя стоит чужой. На подделке держатся SYN
flood и отражённые атаки. Провайдер может отбрасывать такие пакеты на входе в свою сеть: это
фильтрация по RFC 2827 (BCP 38).

## `port` Порт

`category` network · `see` port-scan, firewall · `lessons` G5

Формы: порт, порта, порту, портом, порте, порты, портов, портам, портами, портах

Номер от 0 до 65 535, по которому компьютер различает свои сетевые службы: адрес указывает
машину, порт — программу на ней. По RFC 6335 порты 0–1023 называются системными, на них по
традиции живут известные службы.

## `port-scan` Сканирование портов

`category` network · `see` port, firewall, banner · `lessons` G5

Формы: сканирование портов, сканирования портов, сканированию портов, сканированием портов, сканирование, сканирования, скан

Разведка: атакующий по очереди стучится в порты сервера и по ответам составляет карту открытых
служб. В MITRE CAPEC это CAPEC-300 «Port Scanning», в MITRE ATT&CK — техники T1595 «Active
Scanning» и T1046 «Network Service Discovery».

## `firewall` Межсетевой экран

`category` network · `see` port, port-scan, network-segmentation · `lessons` G5

Формы: межсетевой экран, межсетевого экрана, межсетевому экрану, межсетевым экраном, межсетевом экране, файрвол, файрвола, файрволом

Устройство или программа, которая решает, какой сетевой трафик пропустить, а какой отбросить.
Надёжное правило — запрет по умолчанию: пропускать только то, что явно разрешено (NIST SP 800-41).

## `banner` Баннер

`category` network · `see` port-scan, vulnerability · `lessons` G5

Формы: баннер, баннера, баннеру, баннером, баннере, баннеры

Приветствие, которым сетевая служба встречает подключение. Часто в нём есть название программы и
её версия, а по версии атакующий ищет известные уязвимости. Поэтому версию из баннера лучше
убирать.

## `smb` SMB

`category` network · `see` port, worm · `lessons` K3

Формы: SMB, SMBv1

Server Message Block — протокол Windows для общих папок и принтеров в сети, обычно на TCP-порту
445. Старая версия SMBv1 содержала уязвимость, через которую в 2017 году распространялся
WannaCry (бюллетень Microsoft MS17-010); её советуют отключать.

## `heartbeat` Heartbeat

`category` network · `see` tls, out-of-bounds-read · `lessons` K2

Формы: heartbeat, пульс, пульса, пульсом

Расширение TLS и DTLS из RFC 6520: одна сторона шлёт короткие данные и их длину, другая
возвращает те же данные, и так обе убеждаются, что соединение живо. Ошибка в его обработке в
OpenSSL в 2014 году получила имя Heartbleed.

## `ssh` SSH

`category` network · `see` key-pair, backdoor · `lessons` K7

Формы: SSH, sshd

Протокол защищённого входа на удалённый компьютер и управления им. На сервере его принимает
служба `sshd`: она проверяет пароль или ключ и только потом даёт командную строку. Поэтому код,
который вмешался в эту проверку, открывает дверь в обход паролей.
