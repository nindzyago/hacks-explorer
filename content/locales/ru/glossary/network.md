## `mitm` Человек посередине

`category` network · `see` arp, tls, attacker · `lessons` G1

Формы: человек посередине, человека посередине, man-in-the-middle, MITM

Атака, при которой атакующий встаёт между двумя сторонами разговора: обе думают, что говорят друг
с другом, а на деле всё идёт через него. Он может читать и менять сообщения. В MITRE ATT&CK это
техника T1557 «Adversary-in-the-Middle». Защищает шифрование с проверкой собеседника, например TLS.

## `router` Роутер

`category` network · `see` arp, mitm · `lessons` G1

Формы: роутер, роутера, роутеру, роутером, роутере, роутеры, маршрутизатор, маршрутизатора

Устройство, через которое компьютеры локальной сети выходят в другие сети, например в интернет.
Чтобы отправить что-то наружу, компьютер отдаёт пакет роутеру своей сети.

## `arp` ARP

`category` network · `see` router, mitm · `lessons` G1

Формы: ARP, ARP-таблица, ARP-таблицу, ARP-таблице, ARP-таблицы, ARP-запрос, ARP-запроса, ARP-ответ, ARP-ответа, ARP-ответы

Address Resolution Protocol (RFC 826): по IP-адресу соседа в той же сети узнаёт его физический
MAC-адрес. Компьютер спрашивает всех и запоминает ответ в ARP-таблице. Кто отвечает, ARP не
проверяет, поэтому поддельный ответ может выдать атакующего за роутер.

## `tls` TLS

`category` network · `see` certificate, hsts, mitm · `lessons` G1

Формы: TLS, HTTPS

Transport Layer Security — протокол защищённого соединения; HTTPS — это HTTP поверх TLS. Он
шифрует данные и проверяет сервер по сертификату, поэтому тот, кто стоит посередине, не может ни
прочитать, ни незаметно подменить разговор. Текущая версия TLS 1.3 описана в RFC 8446.

## `certificate` Сертификат

`category` network · `see` tls, domain · `lessons` G1

Формы: сертификат, сертификата, сертификату, сертификатом, сертификате, сертификаты, сертификатов

Электронный документ, который связывает имя сайта с его открытым ключом и подписан центром
сертификации. Браузер проверяет, что сертификат выдан на тот домен, который открыт в браузере,
и подписан тем, кому браузер доверяет. Сертификат говорит, чей это сайт, но не говорит, что сайт честный.

## `hsts` HSTS

`category` network · `see` tls, certificate · `lessons` G1

Формы: HSTS, Strict-Transport-Security

HTTP Strict Transport Security (RFC 6797): заголовок, которым сайт велит браузеру ходить к нему
только по HTTPS. Браузер сам меняет `http` на `https` и не даёт пройти мимо ошибки сертификата.
Первый визит защищает список предзагрузки HSTS в браузерах.

## `network-segmentation` Сегментация сети

`category` network · `see` ransomware, trust-boundary · `lessons` H2

Формы: сегментация сети, сегментации сети, сегментацию сети, сегментацией сети, сегментация, сегментацию, сегментацией

Деление сети на части с правилами, кто к кому может обращаться. Рабочие компьютеры не видят все
серверы, поэтому заражение одной машины не расходится по всей компании.

## `dos` Отказ в обслуживании

`category` network · `see` cia-triad · `lessons` A5

Формы: отказ в обслуживании, отказа в обслуживании, отказе в обслуживании, DoS, DDoS

Атака на доступность: сервис перегружают или ломают так, что законные пользователи не
могут им пользоваться. Если запросы идут сразу с тысяч адресов, это распределённая атака,
DDoS.
