# Каталог уроков

`catalog` ru · `format` 1

Все темы справочника по разделам (M2.1, K112). Раздел — `` ## `B` Название ``, тема —
`` - `B1` Название ``. Урок готов, когда есть его файл `content/lessons/<id>/<язык>.md`; каждый
урок из `content/lessons` должен быть здесь, в своём разделе. Переводы держат те же разделы и
темы в том же порядке. Тексты тем — из `plan/content-catalog.md`. Короткое имя раздела для
кнопки в колонке уроков — после « · » (`` ## `B` Веб: инъекции · Инъекции ``); без него на кнопке
полное название.
