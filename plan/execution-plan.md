## 0. Допущения (подтвердить)

1. Название — Hacks Explorer (K8), подпись «как устроены атаки и как от них защититься».
   Папка на диске остаётся `secviz`, репозиторий на GitHub — `hacks-explorer`. Сайт живёт на
   домене владельца.
2. Стек: Vite + Svelte 5 + TypeScript, сцены в SVG, без бэкенда и базы.
3. Хостинг: Cloudflare (K10). Выпуск делается тегом версии на GitHub: Actions собирает сайт,
   создаёт GitHub Release и выкладывает его как основной. Ветка `main` выкладывается на
   черновой адрес, у pull request свой адрес предпросмотра.
4. Репозиторий на GitHub открытый: код под MIT, тексты и схемы уроков под CC BY-SA 4.0.
   `plan/` и `log/` коммитятся (в них нет чужих материалов), `reference/` нет.
5. Языки: русский и английский сразу; остальные добавляются модулями через pull request
   (файл урока на каждый язык, Markdown — K21). Что делать с неполным переводом, решается в
   дизайне M2.3; до тех пор язык показывается, когда заполнен целиком.
6. Аудитория: новички. Глубина по желанию: у каждого урока уровни «Просто», «По шагам», «Глубже».
7. Урок — пошаговая анимация. Песочницы «попробуй сам» в первой версии нет, но формат урока
   оставляет для неё место (gaps G2).
8. Сцена — схема с границами доверия и иконками в стиле ризографии (K5). Раскладка — один
   экран по образцу Protocol Explorer (K7): схема слева, объяснение справа, таблица шагов
   снизу, уроки и словарь в выдвижной панели.
8a. Урок и переводы хранятся как данные в Markdown (K18), не как код: их можно править в
   pull request без сборки, и чужой pull request не может принести на сайт скрипт.
9. Без аналитики, кук и внешних запросов. Платных API нет.
10. Агенты: Claude Code, до трёх параллельно на волнах контента.

## 1. Цель и не-цели

- Цель первой версии: человек без опыта в безопасности открывает сайт, выбирает тему и за
  3–5 минут видит по шагам, как устроена атака и что её останавливает; при желании раскрывает
  технические детали. Первый выпуск — по три урока в каждом из 12 разделов, 36 уроков (K9);
  всего в каталоге 75 (`plan/content-catalog.md`). Русский и английский.
- Не-цели: учебные стенды для взлома, рабочие эксплойты, учётные записи и прогресс на сервере,
  сертификация, новости об уязвимостях, поиск по базе CVE.

## 2. Приоритеты

Сначала каркас (gate, канал управления, детерминизм), затем один урок насквозь, затем оболочка
вокруг него, затем контент волнами. Точность фактов важнее числа уроков.
